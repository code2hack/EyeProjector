## Objective

Activate the current app saved Click target independently of where the head pointer now points.

## Scope

- Load the typed saved descriptor/mode and resolve a current target for a new click.
- One execution admission/contact owner shared with the later Hold extension; use existing source/session retirement.
- Return execution/availability state for the proposed nonblocking feedback.

## Acceptance and evidence

- One short Function activation produces one click on the resolved target after the pointer moves away.
- Exercise actual original route/contact identity and accepted retirement, not only a helper model.
- Missing/unavailable behavior follows the proposed policy under the authorized plan; no competing Hold owner or registration dependency is introduced.

## Dispatch boundary

The Manager allocates exact files/interfaces, a version-branch base, one Worker, an independent Reviewer, a dedicated worktree and evidence/resources. Shared writers and device windows are coordinated. Source/device/public operations remain bound to that recorded assignment and its resources.
