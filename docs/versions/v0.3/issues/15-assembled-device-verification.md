## Objective

Collect current assembled-device evidence for the agreed v0.3 requirements and selected regression cases.

## Proposed scope

- Exact reviewed assembly/artifact identity and actual Phone/Glasses/HID routes.
- Native navigation, HID roles, registration persistence, Click, Hold and representative context changes.
- Owner-agreed app/screens and regression selection; ChatGPT is an initial candidate rather than a preapproved mandatory app.

## Proposed acceptance and evidence

- Separate host tests, actual input submission, app-observed activation and original retirement facts.
- Use controlled fixture edge records plus agreed real app/control evidence; no private conversation capture is needed.
- Report platform/firmware/app limitations for Owner disposition; do not treat the issue as the first test of individual lifetime contracts.

## Dispatch boundary

After the Owner authorizes the plan, the Manager allocates exact files/interfaces, a version-branch base, one Worker, an independent Reviewer, a dedicated worktree and evidence/resources. Shared writers and device windows are coordinated. This outline authorizes no source, device or public issue operation by itself.
